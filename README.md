# Real-Time Location Tracker

A basic real-time location tracking application that allows users to share and view location updates dynamically. The project demonstrates real-time communication and location handling in a web application.

## Features

- Real-time location updates
- Dynamic location tracking
- Interactive location display
- Client-server communication
- Simple and easy-to-use interface

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Real-Time Communication:** Socket.IO
- **Location Services:** Browser Geolocation API

## How It Works

The application accesses the user's location through the browser's Geolocation API, with the user's permission. Location updates are transmitted to the server and shared with connected clients in real time.

## Learning Objectives

This project demonstrates the fundamentals of real-time communication, geolocation, client-server interaction, and dynamic updates in web applications.

## Privacy

Location access requires user permission. Use location sharing responsibly and only with the knowledge and consent of the people involved.
